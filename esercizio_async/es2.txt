Adesso gestisci la promise con async/await

Una funzione asincrona e dichiarata cosi

async function f () {...}

f torna una promessa.
E possibile gestire cosi le promesse:

let var = f();
var.then(() => {}).catch(() => {}) ...

oppure

try
{
    let var = await f(); // aspetta che si risolva e continua
    console.log(var);
}
catch (err)
{
    console.log(err); // stampa l'argomento di throw
}

riscrivi l'es 1 cosi.
